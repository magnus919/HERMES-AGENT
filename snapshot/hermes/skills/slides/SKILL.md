# Slides

HTML/CSS presentation slides with Chart.js integration.

## When to Use

- Creating presentation slides
- Building pitch decks
- HTML slide generation with Chart.js
- Slide layouts and design
- Copywriting for presentations

## Quick Commands

### Generate Slide
```bash
python3 ~/.hermes/skills/ui-ux-pro-max/scripts/generate-slide.py --topic "<topic>" --layout <layout>
```

### Search Slides
```bash
python3 ~/.hermes/skills/ui-ux-pro-max/scripts/search-slides.py "<query>" [-n <max_results>]
```

### Validate Slide Tokens
```bash
python3 ~/.hermes/skills/ui-ux-pro-max/scripts/slide-token-validator.py --file slides.html
```

## Layout Types

1. **Title Slide** - Hero intro
2. **Section Divider** - Break between sections
3. **Content Slide** - Text + visuals
4. **Two-Column** - Side by side content
5. **Chart Slide** - Data visualization
6. **Quote Slide** - Testimonial/highlight
7. **CTA Slide** - Call to action

## Copywriting Formulas

### AIDA
- Attention → Interest → Desire → Action

### PAS
- Problem → Agitate → Solution
